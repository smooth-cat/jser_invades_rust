你仅可查看和修改 glm-flash.rs

在 demo 函数中 生成一个英雄相关的 structs 和 traits

1. 实现
   1. 共两个英雄 Support 和 Assassin，后续可能有更多英雄
   2. 所有英雄具有 hp 属性，最高 100，最低 0
   3. 两个英雄支持 普通攻击，让被攻击的目标掉 1 滴血
   4. 辅助支持 恢复自身血量，每次 hp+5
   5. 刺客支持刺杀，当自身的 can_kill 属性为 true 时可以将目标 hp 设置为 0
   6. 你需要考虑整个系统的封装 与 可扩展性
2. 使用示例
   1. 生成一个辅助，一个刺客
   2. 刺客对辅助进行一次普通攻击
   3. 辅助回血
   4. 刺客将 can_kill 设置为 true 并刺杀辅助
