一、先看结论

let once = || {

  f()

三、源码打印的地址到底是什么

&source / &inner

println!("{:p}", &source) 和 &inner 打印的是 String 头部对象自身的地址。头部在逻辑上从 source 移到 once、f、inner。

source.as_ptr() / inner.as_ptr()

as_ptr() 才返回 String 堆缓冲区的地址。本例没有修改或扩容 String，所以这个指针值在整条所有权移动链上保持不变，直到 inner 被 drop。

四、MIR 证据：消费 self，再移出字段

// 闭包函数签名：self 按值传入，而不是 &self / &mut self
fn demo::{closure#2}(_1: {closure}) -> () {
  _2 = move (_1.0: String);  // let inner = source
  // ... println!("inner：{:p}", &_2)
  drop(_2);                       // inner 离开作用域，释放堆
}

五、为什么只能调用一次

第一次调用消费了什么

call_once(self, ()) 消费闭包对象，闭包体又把其中的 String 移给 inner。调用结束后，原闭包已不存在，没有第二份 source 可供第二次移出。

如果不调用呢

若 once 从未被调用，它仍然拥有捕获的 String。当 once 自身被 drop 时，捕获字段也会被 drop，同样正确释放 "hello" 的堆缓冲。
