数据范围

UTC 2026-07-01 00:00:00 至 2026-07-31 23:59:59。总数查询条件为 created:2026-07-01..2026-07-31，只统计公开仓库。语言查询使用同一日期条件加 language: 限定，返回仓库的主语言字段。

为什么不直接数 CreateEvent

GitHub 的 CreateEvent 文档定义为创建 branch 或 tag；GH Archive 对应的 2026 年 7 月事件样例也只出现这两种 ref_type。直接数 CreateEvent 会把旧仓库的新分支算成新仓库，所以这里把 GH Archive 用作事件事实核验，而不是错误的仓库创建计数器。
