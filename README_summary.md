# 第 6 集 所有权、借用、生命周期标注

## 所有权    

数据有唯一 拥有者(变量)，拥有者离开，数据释放

### 所有权转移 <sup>do_move fn_move</sup>

1. 编译时 非 Copy 类型数据赋值时发生所有权转移
2. 运行时 栈内存拷贝

### 变量离开？<sup>conflict_read_write</sup>

1. 编译时 **变量的最后一次使用之后**
2. 运行时 函数执行完成 栈帧释放
               **向已初始化的 place 赋值时，旧值需要先被释放**

## 借用？指针！

1. 编译时 有读【写?】权限，但没有销毁权限
2. 运行时 指针

### 种类

读写权限都是深度的

1. 读指针 `&a`    (不可变借用)
2. 写指针 `&mut a` (可变借用)

## 限制：读写互斥，写唯一

1. 读写指针 不能同时存在
2. 所有者 不能在有写指针时读，也不能在有读指针时写
3. 写唯一：同一时间只能有一个写指针, 只能有一个变量在执行写操作

## 生命周期标注

### 为什么有？

黑盒代码产生的结果 的 生命周期无法在编译时确定

### 啥时要？ <sup>life_circle</sup>

1. **返回值是指针** 的时候要 => **确定返回值生命周期**
2. **结构体内有指针** 的时候 => **避免悬垂指针**
